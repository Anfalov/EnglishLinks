# Работа с репозиторием

## Ветки и выпуски

- Основная рабочая ветка — `develop`. Разработка, исправления, обновление баз,
  документации и тестовые сборки выполняются и сохраняются в `develop`.
- Перед изменениями проверь текущую ветку и актуальное состояние `origin/develop`.
  Если открыт `main`, переключись на `develop` до редактирования и коммитов.
  Сохраняй незакоммиченные пользовательские изменения при переключении.
- `main` предназначен для готовых изменений: push с изменениями в `EnglishLinks/`
  автоматически создаёт новую версию, ZIP и GitHub Release. Изменения только
  документации, инструментов и источников релиз не запускают. Не используй `main` для промежуточных
  коммитов, проверки CI или сохранения незавершённой работы.
- Переноси проверенные изменения из `develop` в `main` только в рамках
  запроса пользователя на выпуск или перенос в `main`. Обычная просьба
  исправить код, сохранить работу или отправить её в GitHub означает push в `develop`.
- Для тестовой сборки используй `python tools/package_release.py` в `develop`.
  Не запускай release workflow вручную и не создавай релизные теги ради теста.
- После выпуска синхронизируй `develop` с `main` и продолжай разработку в `develop`.
  Не отправляй обратно в `main` отдельные коммиты с версиями из релизных тегов.

## Автоматическое обновление названий

- Отдельный workflow `Update addon names` запускается вручную или по понедельникам и четвергам
  в 09:00 по Екатеринбургу (04:00 UTC).
  Пользователь разрешил ему обновлять данные через служебную ветку `autoupdate`
  и переносить проверенный результат в `main` без отдельного подтверждения.
- `autoupdate` принадлежит автоматике; ручную разработку веди в `develop`.
- Исходная база — `EnglishLinks/NameData.lua`. Wowhead добавляет и меняет имена;
  другие источники только заполняют отсутствующие ID. Записи не удаляются.
- Wago, QuestV2, связи SkillLineAbility и таблицы названий карт удалены.
  Не возвращай их загрузку или проверки полноты по ним.
- Недоступный источник пропускается с записью в отчёте. Нет изменения имён —
  нет коммита и выпуска. Не меняй даты внутри аддона ради отметки проверки.
- Release workflow только выставляет версию и упаковывает готовый аддон.
  Он не скачивает, не пересобирает и не сверяет базы с исходными снимками.
- Подробности, ручной запуск и ограничения: `docs/AUTO-UPDATE.md`.

Это правило заменяет прежнюю договорённость вести разработку непосредственно
в `main`. Устройство автоматических выпусков описано в `docs/RELEASES.md`.
