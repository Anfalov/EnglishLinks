# EnglishLinks 0.5.0

English names in outgoing game links for WoW Forever 1.60.1.

Extract this folder into your Forever client's Interface/AddOns directory.
The final path must be Interface/AddOns/EnglishLinks/EnglishLinks.toc.
Open chat and Shift-click an item, spell, quest or profession recipe.
EnglishLinks changes the link label; you send the message normally.

Names are bundled. No other addon or name-collection step is required.
Unknown names and items with random affixes keep their original labels.
The addon does not translate incoming chat, tooltips or the game interface.

- /el on, /el off — enable or disable translation.
- /el status — version and status.
- /el coverage — bundled name counts.
- /el type enchant off — disable recipe translation; on enables it.
- /el missing — missing name IDs.
- /el set quest 7 Kobold Camp Cleanup — manual name.
- /el unset quest 7 — remove a manual name.

Disabling the addon does not undo changes already made to your chat input;
clear and reinsert the link to restore its original name.

Recipe labels omit the profession prefix to preserve clickable English recipe
links. Companion links may fail to send even without translation.
Retail and other Classic editions have not been validated.
