# История решений

Current update (2026-10-02): Wago imports, QuestV2 checks and unused
spell-to-profession/map datasets are removed. Earlier entries below record
historical decisions. Current process: [AUTO-UPDATE.md](AUTO-UPDATE.md).

## 0.6.1 — поддержка случайного свойства rand

Предыдущее исследование в 0.6.0 было неполным: наличие бонусного способа
не доказывает ненужность поля rand. Wowhead Forever возвращает имена для
положительных и отрицательных rand ID. В его gear-planner найдены 2 039 ID;
они включены полностью, без переноса ID из других изданий игры.

Параметр называем «случайное свойство», без утверждения, что он устарел.
ID сохраняют знак; они не равны bonus ID. Совпадающие окончания при одновременном
rand и bonus добавляются один раз; неизвестные/конфликтующие значения не переводятся
частично. Примеры ответов Wowhead сохранены рядом с исходным снимком.

Политика Wowhead как источника истины и номера версий без alpha остаётся прежней.
Подробности: `docs/WOWHEAD-SOURCES.md`, `tools/build_random_affixes.py`.

## 0.6.0 — 2026-10-01

### Правило обновления названий

1. Сначала Wowhead Forever: добавляем новые ID, для существующих заменяем
   прежнее название названием Wowhead при любом расхождении.
2. Затем остальные источники: добавляем только отсутствующие ID; уже выбранные
   названия не перезаписываем. При конфликте с Wowhead всегда побеждает Wowhead.
3. Не удаляем запись только потому, что её нет в Wowhead или QuestV2.
   QuestV2 служит только проверкой полноты, а не фильтром допустимых ID.

Это правило применяется к встроенной базе. Явные ручные переименования игрока
через `/el set` сохраняют приоритет. В текущей реализации дополнительные пакеты
загружаются раньше пакета Wowhead; итоговая база эквивалентна указанному порядку.
Правило проверяется в `tests/test_build_wowhead.py` и описано подробнее
в `docs/WOWHEAD-SOURCES.md`.

### Окончания предметов и версии

Для найденных в Forever окончаний ItemRandomSuffix/ItemRandomProperties не
нужны: используется проверенный источник Wowhead item-bonuses (345 бонусов,
50 окончаний). Например, bonus ID 12722 даёт `of the Bear`.
Отдельно восстанавливать импорт двух старых таблиц для этого пути не требуется.
Их отсутствие во всех возможных форматах ссылок Forever не доказано;
проверка ненулевого старого поля остаётся защитой от потери окончания.
Это не означает, что найденные бонусные окончания остаются непереведёнными.

По просьбе пользователя текущая и следующие версии имеют обычный номер
без `alpha`: текущая версия — `0.6.0`, тип файла CurseForge — `Release`.
Номер версии сам по себе не утверждает прохождение проверки в игровом клиенте.

### Изменения

- Wowhead Forever is the primary source for names; all other sources fill gaps.
- QuestV2 now checks coverage only. No names are discarded by this reference.
- Includes 24,062 items, 31,795 spells, 5,250 quests, 154 skills, 434 achievements,
  9 currencies, 113 companion species and 217 summon-spell mount names.
- Translates 345 known item bonuses with 50 distinct English suffixes. Unknown
  bonuses and legacy random-property/suffix IDs preserve the original label.
- Map pins use Map Pin Location, retaining the atlas icon and coordinate payload.
  Removed the unnecessary UiMap name dictionary.
- Archived Wowhead source snapshots and added deterministic import/regression tests.

New suffix/map-pin behavior is verified offline, not yet in the live client.
Target: WoW Forever 1.60.1, Interface 16001.



## 0.5.0 — английские ссылки рецептов

После проверки 0.4.4-alpha.1 пользователь подтвердил работу в Forever.
Подпись enchant теперь содержит английское имя рецепта без префикса профессии.
Тип ссылки, ID, цвет и открываемый рецепт сохраняются. Это решение включено
в 0.5.0. Добавлены значок, скриншот и материалы публикации CurseForge.
Подробности и пределы проверки: docs/RECIPE-LINKS.md.


## Отмена 0.4.3 — только английские кликабельные ссылки

Пользователь отверг вариант «исходная ссылка + перевод рядом». Основная цель
аддона — красивая кликабельная ссылка с английской подписью непосредственно
в чате. Русская/иная локализованная ссылка с пояснением, обычный текст вместо
ссылки и перевод только подсказки эту задачу не решают. Такие изменения
поведения нельзя вводить без согласования с пользователем.

Обход из 0.4.3 отменён; обработчик возвращён к поведению 0.4.2. Проблема
рецептов остаётся открытой. Диагностика enchant:3816 сохранена в
data/link-observations.json: SendChatMessage получает целую английскую ссылку,
но в полученном сообщении отображается некликабельный искажённый текст.
Это локализует наблюдаемое повреждение после передачи в API, но ещё
не определяет виновника (клиент, сервер или обработчик входящего чата).

## 0.4.2 — удаление лишних форматов

По запросу пользователя удалены journal, talentbuild и instancelock. Удалены
категории specialization, journalinstance, journalencounter, journalsection, map,
пункты команд и импорт ChrSpecialization, JournalInstance, JournalEncounter,
JournalEncounterSection, Map. Старые настройки, ручные названия и missing
этих категорий очищаются при загрузке. Такие ссылки остаются без изменений.
Отдельные таланты (spell/talent), метки worldmap и UiMap сохранены.
Отсутствие подтверждённого применения в целевой версии не следовало выдавать
за недостающие обязательные данные или планы развития игры.

## 0.4.1 — исправление питомцев-компаньонов

Пользователь подтвердил строку nonbattlepet:5005 из окна призыва Forever.
В 0.4.0 были имена видов, но не было обработчика этого формата. Добавлен
nonbattlepet → companion. Ненужные для целевой версии battlepet и battlePetAbil
удалены; база 112 видов переименована в companion. Клиентский сбор не добавлялся.
Ручные названия из старого ключа battlepet мигрируют в companion.


## 0.4.0 — дополнения Forever и форматы ссылок

ItemSparse не принят за полную базу предметов. Добавлены 4 796 имён из
закреплённых Forever-снимков QuestieDB и Wowhead gear planner, без конфликтов
с исходными названиями. Добавлены пять валют, 112 видов питомцев и 60 карт.
Точный источник и исходная сборка каждого набора сохранены отдельно.
Исправлено разрешение mount: по ID заклинания. Отдельные таланты используют
spell: и уже поддерживались; прежняя формулировка о неподдерживаемых новых
талантах была слишком широкой. Сбор названий из клиента не возвращён.
Питомцы в журнале, полные talentbuild-ссылки и instancelock остаются отдельными
границами проверки; подробности в SUPPLEMENT-SOURCES.md.

## 0.3.1 — упрощение команд

Удалена пользовательская команда `/el test`. `/el coverage` выводит только
непустые встроенные базы; подготовленные адаптеры без данных не показываются.
Сейчас это item, spell, profession, quest и achievement.

## 0.3.0 — отказ от клиентского сбора

Пользователь сообщил, что массовый сбор заданий работает долго и более половины
запросов попадает в unavailable, и попросил полностью убрать функцию.
В 0.2.1 счётчик объединял неуспешные ответы, ошибки и таймауты 10 секунд;
поздние ответы пропускались. Лимит сервера этим не доказан.

Удалены Collection.lua, очереди, обработчики событий заданий, запоминание имён
из английского клиента, команды collect/export и импорт learned CSV.
Вместо этого поставляется готовая база названий. Старый learned не используется;
его данные не уничтожаются при обновлении, новые записи туда не пишутся.

## 0.3.0 — отказ от двух таблиц случайных свойств

ItemRandomSuffix и ItemRandomProperties были предложены по старым схемам без
подтверждения доступности в Forever. Обе ссылки Wago для 1.60.1.70124 вернули
`{"errors":"Table not found."}`. Пользователь попросил удалить поддержку.

Импортёры и категории suffix/property удалены из текущего набора функций;
повторное скачивание этих таблиц не требуется. Это не доказательство отсутствия
самих случайных свойств в игре. Защитная проверка ненулевого поля случайного
свойства оставлена: такие ссылки не переводятся частично.
Возвращать функцию можно только после обнаружения проверенного источника Forever.
